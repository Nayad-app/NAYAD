# NAYAD PWA v0.3

iPhone дээр Home Screen-д нэмээд апп шиг ажиллуулах PWA prototype.

PWA нь HTTPS эсвэл localhost орчинд ажиллана. ZIP-ийг iPhone дээр задлаад `index.html`-ийг шууд `file://` хэлбэрээр нээхэд service worker суухгүй. Вэб хаяг дээр байршуулсны дараа Safari → Share → Add to Home Screen.

Энэ нь одоогоор prototype; cloud database/authentication дараагийн шатанд нэмэгдэнэ.
