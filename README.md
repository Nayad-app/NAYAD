# NAYAD PWA v1.1

Нийлүүлэгчийн падаан, өглөг, төлбөрийн хугацааг удирдах Supabase Auth/Database-д холбогдсон PWA.

PWA нь HTTPS эсвэл localhost орчинд ажиллана. ZIP-ийг iPhone дээр задлаад `index.html`-ийг шууд `file://` хэлбэрээр нээхэд service worker суухгүй. Вэб хаяг дээр байршуулсны дараа Safari → Share → Add to Home Screen.

## v1.1 — Төлбөрийн төв

- Падааныг эхлээд ноорог хадгалж, шалгасны дараа баталгаажуулна.
- Баталгаажсан падааны төлөх өдөр, хугацаа хэтрэлт, 7 хоногийн төлөвийг харуулна.
- Нийлүүлэгч бүрийн хөнгөлөлтийн хувь, хүчинтэй хугацааг падаан дээр гараар тохируулна.
- Төлбөрийг нэг эсвэл олон падаанд хуваарилж, баталгаажуулалтын түүх хадгална.
- Буруу төлбөрийг устгахгүй; шалтгаантай буцаалт хийнэ.
- Хугацаа сунгасан тохиролцоонд шинэ огноо, дүн, тайлбар хадгалж анхны хугацааг хэвээр үлдээнэ.
- Апп нээлттэй болон дахин идэвхжих үед хугацааны сануулгыг шинэчилнэ.

Банк/QPay-аар мөнгө шилжүүлэх gateway энэ хувилбарт ороогүй; төлбөрийн бүртгэл ба өглөгийн тооцоолол орсон.
